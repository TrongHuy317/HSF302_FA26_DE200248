## Hướng dẫn chạy ứng dụng (TODO 13)
1. Khởi động SQL Server trên cổng mặc định `1433`.
2. Đảm bảo cơ sở dữ liệu `StudentDB` đã được tạo qua `database.sql`.
3. Chạy ứng dụng bằng lệnh:
   ```powershell
   .\mvnw.cmd spring-boot:run
   ```
4. Truy cập trình duyệt:
   - Trang danh sách: [http://localhost:8080/students](http://localhost:8080/students)
   - Kiểm tra Bootstrap offline: [http://localhost:8080/css/bootstrap.min.css](http://localhost:8080/css/bootstrap.min.css)
